# Project Abandoned

This project was intended to find a replacement for the built-in search routine found in the WonderCMS package from v3.5.0.

I'm no coder and was using ChatGPT to write the code for me. In the end it was found easier to produce a multi-level search facility using the functions.php approach rather than a plugin.

For further information about the resulting search routine see the [GregChapman.uk](https://gregchapman.uk/wondercms/developers/site-search) site.
